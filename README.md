## 📌 О репозитории

Данный репозиторий содержит выполненные лабораторные работы по дисциплине «Введение в бэкенд-разработку».

## 🧪 Лабораторная работа №1 — Настройка среды и первый HTTP-сервер

📂 [`Laba1`](./Laba1/)

В первой лабораторной работе настраивается среда разработки и создаётся первый HTTP-сервер на **Node.js + Express**.

**Вариант:** 5
**Уровень:** повышенный

### В рамках работы рассматриваются

* установка Node.js, создание проекта через `npm`, автоперезапуск сервера с помощью **Nodemon**;
* эндпоинты и маршрутизация: текстовый ответ, JSON-эндпоинты (`/api/movies`, `/api/cinemas`), параметр в пути (`/api/movies/:id`);
* обработка несуществующих маршрутов (`404`);
* логирование всех запросов в консоль (метод + URL + время);
* проверка сервера с помощью **cURL** (команды лежат в `curl_commands.txt`).

## 🔄 Лабораторная работа №2 — CRUD API

📂 [`Laba2`](./Laba2/)

Во второй лабораторной работе создаётся REST-подобный API с хранением данных в памяти сервера.

**Вариант:** 5 — сущность «Фильмы» (`movies`)
**Уровень:** продвинутый

### CRUD

| Операция   | Назначение       | HTTP-метод      |
| ---------- | ---------------- | --------------- |
| **Create** | Создание данных  | `POST`          |
| **Read**   | Получение данных | `GET`           |
| **Update** | Изменение данных | `PUT` / `PATCH` |
| **Delete** | Удаление данных  | `DELETE`        |

### В рамках работы рассматриваются

* HTTP-методы `GET`, `POST`, `PUT`, `PATCH`, `DELETE`;
* CRUD-операции над коллекцией в памяти сервера;
* HTTP-коды состояния `200`, `201`, `204`, `400`, `404`, `500`;
* валидация входных данных;
* поиск, сортировка и пагинация (`?search=`, `?sort=&order=`, `?page=&limit=`);
* массовые операции (`DELETE /movies`, `POST /movies/bulk`);
* статистика и связанные элементы (`/movies/stats`, `/movies/:id/related`);
* логирование запросов в файл `access.log`;
* глобальный обработчик ошибок;
* тестирование API в **Postman** с автотестами и Collection Runner.

Для проверки API используется коллекция запросов:

📄 [`Lab2_CRUD_API.postman_collection.json`](./Laba2/Lab2_CRUD_API.postman_collection.json)

## ▶️ Как запустить проекты

Для каждой лабораторной работы:

```bash
cd Laba2        # или Laba1
npm install
npm start       # или npm run dev (с автоперезапуском через Nodemon)
```

После запуска сервер доступен по адресу `http://localhost:3000`. Точные команды запуска и проверки указаны в `README.md` каждой лабораторной работы.
