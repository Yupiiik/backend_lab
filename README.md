## 📌 О репозитории

Данный репозиторий содержит выполненные лабораторные работы по дисциплине «Введение в бэкенд-разработку».

## 🧪 Лабораторная работа №1 — Настройка среды и первый HTTP-сервер

📂 [`Laba1`](./Laba1/)

В первой лабораторной работе настраивается среда разработки и создаётся первый HTTP-сервер на **Node.js + Express**.

**Вариант:** 5
**Уровень:** повышенный

### В рамках работы рассматриваются

* установка Node.js, создание проекта через `npm`, автоперезапуск сервера с помощью **Nodemon**;
* эндпоинты и маршрутизация: текстовый ответ, JSON-эндпоинты (`/api/movies`, `/api/cinemas`), параметр в пути (`/api/movies/:id`);
* обработка несуществующих маршрутов (`404`);
* логирование всех запросов в консоль (метод + URL + время);
* проверка сервера с помощью **cURL** (команды лежат в `curl_commands.txt`).

➡️ **[Перейти к лабораторной работе №1](./Laba1/README.md)**

## 🔄 Лабораторная работа №2 — CRUD API

📂 [`Laba2`](./Laba2/)

Во второй лабораторной работе создаётся REST-подобный API с хранением данных в памяти сервера.

**Вариант:** 5 — сущность «Фильмы» (`movies`)
**Уровень:** продвинутый

### CRUD

| Операция   | Назначение       | HTTP-метод      |
| ---------- | ---------------- | --------------- |
| **Create** | Создание данных  | `POST`          |
| **Read**   | Получение данных | `GET`           |
| **Update** | Изменение данных | `PUT` / `PATCH` |
| **Delete** | Удаление данных  | `DELETE`        |

### В рамках работы рассматриваются

* HTTP-методы `GET`, `POST`, `PUT`, `PATCH`, `DELETE`;
* CRUD-операции над коллекцией в памяти сервера;
* HTTP-коды состояния `200`, `201`, `204`, `400`, `404`, `500`;
* валидация входных данных;
* поиск, сортировка и пагинация (`?search=`, `?sort=&order=`, `?page=&limit=`);
* массовые операции (`DELETE /movies`, `POST /movies/bulk`);
* статистика и связанные элементы (`/movies/stats`, `/movies/:id/related`);
* логирование запросов в файл `access.log`;
* глобальный обработчик ошибок;
* тестирование API в **Postman** с автотестами и Collection Runner.

Для проверки API используется коллекция запросов:

📄 [`Lab2_CRUD_API.postman_collection.json`](./Laba2/Lab2_CRUD_API.postman_collection.json)

➡️ **[Перейти к лабораторной работе №2](./Laba2/README.md)**

## 🧭 Лабораторная работа №3 — Маршрутизация, параметры пути и query-параметры

📂 [`Laba3`](./Laba3/)

В третьей лабораторной работе разрабатывается API на **Python + Flask**. Работа посвящена маршрутизации, передаче параметров через URL, обработке вложенных ресурсов и проверке входных данных.

**Вариант:** 5 — сущность «Фильмы» (`movies`)  
**Уровень:** продвинутый

### В рамках работы рассматриваются

* создание HTTP-маршрутов Flask для получения списка фильмов и отдельного фильма;
* параметры пути и query-параметры;
* поиск по названию, фильтрация, сортировка и пагинация;
* вложенные ресурсы: актёры фильма, кинотеатры и фильмы определённого жанра;
* многоуровневые маршруты с несколькими параметрами пути;
* проверка входных параметров и обработка ошибок `400`, `404` и `500`;
* статистика фильмов, включая количество и средний рейтинг;
* логирование запросов: метод, URL, время и IP-адрес клиента;
* тестирование API с помощью **Postman**.

Для проверки запросов используется коллекция Postman:

📄 [`Laba3_Postman.json`](./Laba3/Laba3_Postman.json)

➡️ **[Перейти к лабораторной работе №3](./Laba3/README.md)**

## ▶️ Как запустить проекты

Команды запуска зависят от используемого стека.

**Лабораторные работы №1 и №2 (Node.js + Express):**

```bash
cd Laba2        # или Laba1
npm install
npm start       # либо npm run dev, если предусмотрено package.json
```

**Лабораторная работа №3 (Python + Flask, Windows PowerShell):**

```powershell
cd Laba3
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

После запуска сервер ЛР3 доступен по адресу `http://127.0.0.1:3000`. Для его проверки импортируйте `Laba3/Laba3_Postman.json` в Postman. Подробные инструкции приведены в README соответствующей лабораторной работы.
